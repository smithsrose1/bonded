# Bonded - a virtual pet to share with your loved one.

Welcome to Bonded! This game allows you and a special someone, share a pet virtually!

## Instructions for game play

1. Log in/Sign Up
2. Enter in a code your loved one gave you, or create a new game and share the code with your loved one.
3. Only 2 players can share one pet at a time- *your pet can only have 2 parents!*
4. When starting a new game (you cannot have another game running), give your pet a name and color. Design your pet's room too!
5. Take care of your kitty:
- Feed, Clean, Play, and put your kitty to bed appropriately. 
- Features real time updates between players, with a message board showing past updates!
6. Have fun :D


## Future Features:

1. Real-time chat services between you and your loved one to improve communications.
2. Different pets and animations for each.
